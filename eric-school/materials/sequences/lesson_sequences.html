Sequences

Maths 60 minutes
01

Term-to-term rules

10 min

A sequence is a list of numbers following a pattern. Each number is called a term.

The term-to-term rule tells you how to get from one term to the next — e.g. "add 4", "subtract 3", or "multiply by 2". To continue a sequence, apply the rule to the last term you know.

Worked examples: 3, 7, 11, 15, 19, ...  →  rule is add 4 each time.

50, 44, 38, 32, ...  →  rule is subtract 6 each time.

Not every rule adds or subtracts — e.g. 2, 6, 18, 54, ...  →  rule is multiply by 3 each time.

02

Special sequences

10 min

Some sequences come up so often they have their own names — worth recognising on sight.

NameSequencePattern
Square numbers1, 4, 9, 16, 25, ...n × n
Cube numbers1, 8, 27, 64, 125, ...n × n × n
Triangular numbers1, 3, 6, 10, 15, ...add 2, then 3, then 4, then 5, ...
Fibonacci-type1, 1, 2, 3, 5, 8, 13, ...each term = sum of the two before it

Fibonacci-type sequences don't have to start with 1, 1 — any sequence built by adding the previous two terms follows the same idea, e.g. 3, 5, 8, 13, 21, ...

03

Finding the nth term

14 min

The nth term is a formula that lets you jump straight to any term, without listing every one before it.

For a sequence where you add (or subtract) the same amount each time (called an arithmetic sequence), use:

nth term = dn + (a − d)

where d = the common difference (what you add/subtract each time), and a = the first term.

Worked example, step by step: 3, 7, 11, 15, 19, ...

1. Common difference d = 4 (each term goes up by 4)

2. First term a = 3

3. a − d = 3 − 4 = −1

4. nth term = 4n − 1

Check: n=1 → 4(1)−1 = 3 ✓  ·  n=5 → 4(5)−1 = 19 ✓

Another, with a negative difference: 50, 44, 38, 32, ...

d = −6, a = 50, a − d = 50 − (−6) = 56  →  nth term = −6n + 56

04

Using the nth term

12 min

Finding a specific term: substitute the term number in for n.

nth term = 3n + 4  →  10th term = 3(10) + 4 = 34

Checking if a number is in the sequence: set the nth term formula equal to that number and solve for n. If n comes out as a positive whole number, it's in the sequence; if not, it isn't.

Worked example: is 50 a term in the sequence with nth term 4n − 1?

4n − 1 = 50  →  4n = 51  →  n = 12.75  →  not a whole number  →  No

Another: is 47 a term in the sequence with nth term 3n + 2?

3n + 2 = 47  →  3n = 45  →  n = 15  →  whole number  →  Yes (it's the 15th term)

05

GCSE-style review questions

14 min

1. State the term-to-term rule for 45, 38, 31, 24, ...

[1 mark]
Subtract 7 each time (1)

2. Find the 6th term of the sequence 4, 9, 14, 19, ...

[2 marks]
nth term = 5n − 1 (1)   6th term = 5(6) − 1 = 29 (1)

3. Find the nth term of the sequence 6, 11, 16, 21, ...

[2 marks]
d = 5, a − d = 6 − 5 = 1 (1)   = 5n + 1 (1)

4. Is 100 a term in the sequence with nth term 4n + 3? Show your working.

[2 marks]
4n + 3 = 100 → 4n = 97 → n = 24.25 (1)   not a whole number, so No (1)

5. The first term of a sequence is 5 and the term-to-term rule is "add 6". Find the nth term.

[3 marks]
d = 6 (1)   a − d = 5 − 6 = −1 (1)   nth term = 6n − 1 (1)

Tip: once you have an nth term formula, always check it by substituting n = 1 — it should give you back the first term of the sequence.
