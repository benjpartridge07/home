Atomic structure & the periodic table

Chemistry 60 minutes
01

Inside the atom

10 min

Every atom has a tiny, dense nucleus at its centre (protons + neutrons), surrounded by electrons moving in shells. The atom's radius is about 1 × 10-10 m — but the nucleus is around 1/10,000 of that, so almost all of an atom's mass is packed into a space that's almost all empty otherwise.

An atom has no overall charge — because the number of protons (+) always equals the number of electrons (−) in a neutral atom, the charges cancel out. All atoms of a given element have the same number of protons.

02

Atomic number, mass number & isotopes

10 min

Atomic number (bottom number, or the smaller one) = number of protons = number of electrons in a neutral atom. It's what makes an element that element.

Mass number (top number, or the bigger one) = number of protons + number of neutrons.

So: number of neutrons = mass number − atomic number.

Isotopes are atoms of the same element (same number of protons) with a different number of neutrons (and therefore a different mass number). Isotopes of an element have the same chemical properties (chemistry is controlled by electrons), but different physical properties like mass and density — some isotopes are also radioactive.

Relative atomic mass (Ar) is the weighted mean mass of all the naturally occurring isotopes of an element, compared with 1/12th the mass of an atom of carbon-12:

Ar = (mass of isotope 1 × % abundance) + (mass of isotope 2 × % abundance) + … ÷ 100

Example: chlorine is 75% chlorine-35 and 25% chlorine-37. Ar = (35 × 75 + 37 × 25) ÷ 100 = (2625 + 925) ÷ 100 = 35.5.

03

Electronic structure

10 min

Electrons occupy shells (energy levels) around the nucleus. The lowest-energy shell (closest to the nucleus) fills up first, then the next, and so on. For the first 20 elements, the maximum number of electrons per shell is:

  1. 1st shell: up to 2
  2. 2nd shell: up to 8
  3. 3rd shell: up to 8

Example: sodium has atomic number 11, so it has 11 electrons: 2, 8, 1. Silicon has atomic number 14: 2, 8, 4.

This links directly to the periodic table: the number of electrons in the outer shell = group number (for groups 1–7 in this simplified view), and the number of occupied shells = period number (the row it's in). Elements in the same group have the same number of outer electrons, which is why they react in similar ways.

04

Developing the periodic table

10 min

Early chemists tried arranging the known elements in order of atomic weight. In 1864, John Newlands proposed his "Law of Octaves" — every 8th element (in weight order) seemed to have similar properties. But his table had problems: it forced some very different elements into the same group, and it left no gaps for elements that hadn't been discovered yet — so it wasn't widely accepted.

In 1869, Dmitri Mendeleev published a table that mostly followed atomic weight order, but he sometimes swapped elements to keep ones with similar properties in the same column. Crucially, he left gaps for elements he believed hadn't been discovered yet, and used the pattern to predict their properties. When those elements (like germanium) were later discovered and matched his predictions almost exactly, it gave scientists confidence that his arrangement reflected something real.

The modern periodic table arranges elements in order of increasing atomic (proton) number, not weight — which is what fixed the few places where weight order had given the wrong sequence. Elements in the same vertical group have the same number of outer-shell electrons and similar chemical properties; elements in the same horizontal period have the same number of occupied electron shells.

06

Three key groups: 0, 1 & 7

12 min

Group 0 — Noble gases

  • He, Ne, Ar, Kr, Xe
  • Full outer shell → very unreactive (inert)
  • Single atoms (monatomic gases)
  • Boiling point increases down the group
  • Uses: filament lamps, balloons (He), lighting (Ne)

Group 1 — Alkali metals

  • Li, Na, K (Rb, Cs)
  • 1 outer electron, easily lost → 1+ ion
  • Soft, low density (float on water); low melting point
  • Reactivity increases down the group
  • Metal + water → metal hydroxide + hydrogen
  • Stored under oil

Group 7 — Halogens

  • F, Cl, Br, I — diatomic molecules (e.g. Cl2)
  • 7 outer electrons, gain 1 → 1− ion
  • Reactivity decreases down the group
  • Melting/boiling point increases down the group (F2, Cl2 gases → Br2 liquid → I2 solid)
  • A more reactive halogen can displace a less reactive one from a salt solution

Why the trends happen: going down Group 1, the outer electron is further from the nucleus and more shielded by inner shells, so it's easier to lose — reactivity increases. Going down Group 7, the outer shell needing one more electron is also further out and more shielded, so it's harder to attract an extra electron — reactivity decreases.

07

GCSE-style review questions

12 min

1. An atom of potassium has 19 protons and 20 neutrons. State its mass number and its number of electrons.

[2 marks]
Mass number = 19 + 20 = 39 (1); number of electrons = number of protons = 19 (1).

2. Explain what is meant by the term "isotopes".

[2 marks]
Atoms of the same element (same number of protons) (1) with a different number of neutrons / different mass number (1).

3. Explain why Mendeleev left gaps in his periodic table, and why this was important.

[3 marks]
He left gaps for elements he believed had not yet been discovered (1). He used the gaps to predict the properties of these missing elements (1). When elements matching his predictions (e.g. germanium) were later discovered, it confirmed his table was a valid way of organising the elements (1).

4. Give the electronic structure of an aluminium atom (atomic number 13), and state which group and period it is in.

[3 marks]
Electronic structure: 2, 8, 3 (1). Group 3, since it has 3 outer electrons (1). Period 3, since it has 3 occupied shells (1).

5. Sodium reacts vigorously with water, but lithium reacts less vigorously. Explain this difference in terms of electronic structure.

[3 marks]
Sodium's outer electron is in a shell further from the nucleus than lithium's (1). It is more shielded by inner shells (1), so it is lost more easily, making sodium more reactive (1).

6. Chlorine can displace bromine from a solution of potassium bromide, but iodine cannot. Use this to place chlorine, bromine and iodine in order of reactivity, and explain your reasoning.

[3 marks]
Order (most to least reactive): chlorine, bromine, iodine (1). A more reactive halogen displaces a less reactive one from solution, so chlorine displacing bromine shows chlorine is more reactive than bromine (1). Reactivity decreases down Group 7, which is consistent with iodine being unable to displace either (1).

7. Argon is used to fill the space inside filament light bulbs. Suggest why argon, rather than oxygen, is used for this.

[2 marks]
Argon is a noble gas with a full outer shell, so it is very unreactive/inert (1). This stops the hot metal filament from reacting (e.g. burning/oxidising), unlike oxygen which would react with it (1).

Tip: questions about Groups 1 and 7 love asking "why" a trend happens, not just "what" the trend is. Always answer in terms of the outer electron being further from the nucleus and more shielded as you go down a group — that single idea explains both trends.
